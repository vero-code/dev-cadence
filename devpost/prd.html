Checkable Acceptance Criteria

1. Docking & Extension Lifecycle

  • ✓ Panel slides out smoothly on Devpost upon clicking extension icon.
  • ✓ Closing and reopening panel retains the active month view and form state without resetting.

2. Log & Edit Hackathon Modal

  • ✓ Form captures Name, Deadline date, Status dropdown, Work date range, and Color/Emoji selection.
  • ✓ Saving an entry updates both calendar day shading and appends a row in the pipeline table instantly.
  • ✓ Editing an entry updates the dates and colors in place; deleting an entry clears its shading.

3. Calendar Visualization & Split Overlap

  • ✓ Work dates shade the calendar cells with the assigned hackathon color/badge.
  • ✓ When two hackathons share work dates, the overlapping calendar cells split visually to show both commitments.
  • ✓ Month navigation buttons (< and >) seamlessly switch months and re-render scheduled blocks.

4. Workload Capacity & Rest Warning

  • ✓ Accurately counts committed days and calculates remaining free days in the month.
  • ✓ Displays an alert warning when remaining free days drop below the user-configured rest days target.

5. Local Persistence

  • ✓ Browser reload or tab close preserves all hackathons, rest targets, and edits in local storage.
Consequential States & Boundaries
First Use / Empty State:

Empty calendar displays "Add a hackathon to start planning", table shows empty prompt, capacity displays 0 committed days.

Normal Active State:

Calendar populated with color-coded work ranges and deadline flags; pipeline table active with status badges and edit/delete triggers.

Collision / Overlap State:

Days claimed by multiple hackathons split their cells diagonally or vertically with dual colors/chips so conflicting sprints are instantly obvious.

Overcommitted Rest Warning:

When logged work days crowd out the configured rest threshold, capacity bar highlights an amber warning with remaining free days count.

Decisions & Scope Cuts
In-Context Side Panel over Tab Switching:

Prevents participants from having to alternate between Google Sheets and Devpost. The calendar lives directly alongside active hackathon listings.

Split Cells for Overlapping Sprints:

Rather than disallowing overlaps, splitting the cells gives the user clear feedback while allowing deliberate multi-tasking.

Cut: Automated DOM Scraping & Cloud Sync:

Deferred to later versions to keep the 2–4 hour PoC completely resilient and focused on the core pacing experience.
