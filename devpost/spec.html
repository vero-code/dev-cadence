// Hackathon item schema
interface Hackathon {
  id: string;               // UUID or timestamp
  name: string;             // Hackathon name (e.g. "Cloud Sprint")
  deadline: string;         // ISO date "YYYY-MM-DD"
  status: string;           // "Not registered" | "Early application" | "Waiting for API key" | custom
  startDate: string;        // ISO date "YYYY-MM-DD"
  endDate: string;          // ISO date "YYYY-MM-DD"
  color: string;            // Hex code "#06b6d4" | "#f59e0b" | "#10b981"
  emoji: string;            // Emoji chip "⚡" | "🚀" | "🛠️"
}

Important Failure Modes & Fallback Strategies
Running in Local Browser Preview (outside Extension):

storage.js detects absence of chrome.storage and seamlessly reads/writes to window.localStorage, guaranteeing identical behavior in development.

Invalid Date Range in Form:

If end date is earlier than start date, LogModal.jsx flags the field with a red border, displays an inline error message, and disables the Save button.

Empty Storage Hydration:

When opened for the first time or if storage is cleared, the app gracefully initializes default settings (8 rest days) and empty hackathon array, rendering the friendly empty state.
