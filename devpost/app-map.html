Dev Cadence

🧭 Reference Code Route

Three key locations that define Dev Cadence's unique behavior:

1. Date Collision Math & Split Gradients
src/utils/calendarUtils.js → generateCalendarDays & getDayCellBackground

Calculates active events across day boundaries. When 2 or more hackathons overlap on a day cell, getDayCellBackground computes a multi-stop diagonal CSS linear gradient (135deg) so visual collisions are instantly obvious without opening a details dialog.

2. Visual Range Selection & Preview Shading
src/components/CalendarGrid.jsx → isDayInRangePreview & onDateRangeClick

Supports direct two-click range selection on the calendar grid. Hovering over candidate dates renders a luminous dashed preview ribbon with real-time duration tooltips, pre-filling the modal with exact dates.

3. Dual Chrome Storage Bridge
src/utils/storage.js → getStoredData & saveHackathons

Abstracts persistence across runtime environments. Inspects typeof chrome !== 'undefined' && chrome.storage; uses chrome.storage.local inside the Chrome Side Panel, and cleanly falls back to window.localStorage during local browser dev sessions.

🔧 "To Change This, Start Here"

🎨 Adjust Color Palette or Emoji Choices

Modify COLOR_PALETTE and EMOJI_OPTIONS at the top of src/components/LogModal.jsx.

📋 Add or Modify Application Statuses

Update STATUS_OPTIONS in src/components/LogModal.jsx and corresponding CSS chips in src/index.css.

🛡️ Change Default Target Rest Days

Edit DEFAULT_SETTINGS in src/utils/storage.js or configure via the Settings modal in the app UI.

📦 Update Chrome Extension Permissions

Review public/manifest.json for Manifest V3 permissions, icons, and side panel default path.

💡 A Practice to Reuse

Context-First Input Over Form-First Guessing

When building scheduling, capacity, or resource planning tools, avoid forcing users into a modal dialog with blank date pickers. In our final review, enabling users to click start and end dates directly on the visual calendar eliminated cognitive friction and date guessing because the user can see their existing commitments and gaps right as they make their decision.
